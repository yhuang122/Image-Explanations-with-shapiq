# Insertion/Deletion Experiment

Full pipeline to reproduce the insertion/deletion curves (Figure 3) for CLIP ViT-B/16 on MS COCO.

## Overview

1. **explain_mscoco.py** — computes Shapley/Banzhaf interaction values (`.pkl` files) for each image
2. **insertion_deletion.py** — uses the `.pkl` files to compute insertion/deletion curves and AID scores
3. **plot_insertion_deletion.py** — plots the curves from the saved `.npy` results

All results go into `results/`.

---

## Prerequisites

`mscoco_predictions.csv` must exist (generated by `data/data.ipynb`). Copy it into the output folder.


## Run the full pipeline 

## Run steps individually

All `explain_mscoco.py` commands must be run from the `experiments/` directory.

### Step 1 — Generate interaction values

Run once per mode (4 total). Each takes several hours for 1000 images.

```bash
cd XXXXX/Image-Explanations-with-shapiq/experiments

# shapley
python explain_mscoco.py --model_name openai/clip-vit-base-patch16 \
    --path_input XXXXX/Image-Explanations-with-shapiq/results/openai/clip-vit-base-patch16 \
    --path_output XXXXX/Image-Explanations-with-shapiq/results/openai/clip-vit-base-patch16/shapley \
    --start 0 --stop 1000 --mode shapley --p_sampler 0.5 --budget 256 --batch_size 64 --random_state 0

# banzhaf p=0.3
python explain_mscoco.py --model_name openai/clip-vit-base-patch16 \
    --path_input XXXXX/Image-Explanations-with-shapiq/results/openai/clip-vit-base-patch16 \
    --path_output XXXXX/Image-Explanations-with-shapiq/results/openai/clip-vit-base-patch16/banzhaf/0.3 \
    --start 0 --stop 1000 --mode banzhaf --p_sampler 0.3 --budget 256 --batch_size 64 --random_state 0

# banzhaf p=0.5
python explain_mscoco.py --model_name openai/clip-vit-base-patch16 \
    --path_input XXXXX/Image-Explanations-with-shapiq/results/openai/clip-vit-base-patch16 \
    --path_output XXXXX/Image-Explanations-with-shapiq/results/openai/clip-vit-base-patch16/banzhaf/0.5 \
    --start 0 --stop 1000 --mode banzhaf --p_sampler 0.5 --budget 256 --batch_size 64 --random_state 0

# banzhaf p=0.7
python explain_mscoco.py --model_name openai/clip-vit-base-patch16 \
    --path_input XXXXX/Image-Explanations-with-shapiq/results/openai/clip-vit-base-patch16 \
    --path_output XXXXX/Image-Explanations-with-shapiq/results/openai/clip-vit-base-patch16/banzhaf/0.7 \
    --start 0 --stop 1000 --mode banzhaf --p_sampler 0.7 --budget 256 --batch_size 64 --random_state 0
```

### Step 2 — Insertion/deletion

```bash
cd XXXXX/Image-Explanations-with-shapiq

python experiments/migrated/insertion_deletion.py \
    --model_name openai/clip-vit-base-patch16 \
    --path_input XXXXX/Image-Explanations-with-shapiq/results/openai/clip-vit-base-patch16 \
    --path_output XXXXX/Image-Explanations-with-shapiq/results/openai/clip-vit-base-patch16 \
    --start 0 --stop 1000
```

Output: `results/openai/clip-vit-base-patch16/mscoco_aid_fixlip_0_1000.npy` and `.csv`
