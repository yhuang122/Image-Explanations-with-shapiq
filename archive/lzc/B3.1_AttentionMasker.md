# B3.1 — AttentionMasker Implementation

> 2026-06-14

---

## Core Innovation

| | VisionMeanMasker | AttentionMasker |
|---|---|---|
| Occlusion target | **Pixel-level** — multiply pixels by 0 | **Latent space** — inject `-inf` into self-attention |
| Mechanism | Image turns black → encoder sees black patches | Encoder "doesn't know" masked patches exist |
| Fidelity | May introduce OOD signal (black patch is itself a "signal") | Closer to "feature removal" semantics |

---

## Architecture

```
ImageImputer.forward_1d()
  ├── segmenter.generate_masks() → PhysicalMask
  ├── AttentionMasker.apply()
  │     ├── pixel mask → per-patch mean → masked patch IDs
  │     └── _compute_attention_bias() → (N, 1, seq_len, seq_len) bias
  └── model(**inputs)
        └── [12× self_attn pre_hooks fire]
              └── inject bias into causal_attention_mask
                    → masked patch keys invisible to all queries (incl. CLS)
```

For ViT-B/32: 224×224 → 7×7=49 patches → 50 tokens (CLS + 49).  
Masked patches are determined per 32×32 region (mean pixel mask < 0.5).

## Bugs Fixed

| Bug | Root cause | Fix |
|-----|-----------|-----|
| Attention heatmap all-white | Row + col both set to `-inf` → softmax `0/0 = NaN` | Only mask key dimension (col), not query (row) |
| Inconsistent hook return | Sometimes returned `None`, sometimes `(args, kwargs)` | Always return `(args, kwargs)` |
| SDPA ignoring mask | Flash attention skips injected `attn_mask` | Load model with `attn_implementation="eager"` |

---

## Results

Both heatmaps (VisionMean vs Attention) correctly identify the dog face region as the highest-impact area. The two maskers produce similar spatial distributions, with the Attention masker operating in latent space (key-level occlusion) rather than at the pixel level.

## Usage

```python
from ImputerFactory import ImageImputerFactory
from ImputerFactory.data import MaskerConfig

factory = ImageImputerFactory()
attn_cfg = MaskerConfig(strategy="attention")
imputer = factory.build(model, processor, image, text, masker_config=attn_cfg)
game = VisionLanguageGame(imputer, batch_size=64)
```
