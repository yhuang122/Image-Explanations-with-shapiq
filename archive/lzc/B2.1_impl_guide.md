## 实现细节

### 1. 梯度提取（gradient_guided.py `setup()`）

```python
def setup(self, model, image, processor, text):
    device = next(model.parameters()).device

    # 预处理（图片保留梯度，文本不需要梯度）
    img_inputs = processor(images=image, return_tensors="pt")
    pixel_values = img_inputs["pixel_values"].to(device)
    pixel_values.requires_grad = True

    txt_inputs = processor(text=text, return_tensors="pt", padding=True)

    # 前向：完整 CLIP 模型（图文双编码器）
    outputs = model(
        pixel_values=pixel_values,
        input_ids=txt_inputs["input_ids"].to(device),
        attention_mask=txt_inputs["attention_mask"].to(device),
    )

    # 反向：从图文相似度反传
    score = outputs.logits_per_image.sum()
    score.backward()
    grad = pixel_values.grad  # (1, 3, 224, 224)
```

关键点：
- 梯度 shape = `(1, 3, 224, 224)`，和 CLIP 输入分辨率一致
- `logits_per_image` 是 CLIP 的图文余弦相似度矩阵（未缩放版本）
- `sum()` 把所有 batch 维度的相似度聚合成标量再反向传播

### 2. Saliency map（梯度 → 显著性图）

```python
# |grad| 跨通道平均 → (224, 224)
saliency = grad.abs().mean(dim=1).squeeze(0)
saliency = saliency.detach().cpu().numpy()

# 归一化到 [0, 1]
saliency = (saliency - saliency.min()) / (saliency.max() - saliency.min() + 1e-8)
```

**已知问题**：raw `|grad|` 在暗色均匀背景（天空）上的梯度幅度可能高于前景物体。标准改进方向：
- `gradient × input`（乘积抑制低像素值区域）
- SmoothGrad（加噪平均）
- 用 vision encoder 最后一层特征图代替输入像素梯度

### 3. SLIC 超像素分割

```python
from skimage.segmentation import slic

saliency_rgb = np.stack([saliency] * 3, axis=-1)  # SLIC 需要 3 通道输入

region_labels = slic(
    saliency_rgb,
    n_segments=self.n_players_image,  # 目标区域数（≈49）
    compactness=5.0,
    start_label=0,
)  # → (224, 224) int, 每个像素标记其所属 region id

actual_n = region_labels.max() + 1  # 实际区域数（可能 ≠ n_segments）
self._region_map = torch.from_numpy(region_labels).long()
```

关键点：
- SLIC 输入是 saliency map（不是原图），所以区域边界会跟随 saliency 的变化
- 高 saliency 区域 → 更多小块；低 saliency 区域 → 更少大块
- `actual_n` 是实际产生的区域数，**必须用它更新 layout**，不能直接用 config 的 `n_players_image`

### 4. Mask 生成（region → pixel 映射）

```python
def _generate_image_mask(self, coalitions: np.ndarray) -> torch.Tensor:
    coalition_t = torch.from_numpy(coalitions)          # (N, n_regions)
    # 高级索引：coalition 的每个 region 映射到对应像素
    binary_masks = coalition_t[:, self._region_map.to(coalition_t.device)]
    # → (N, 224, 224)
    # 扩展到 (N, 3, 224, 224)
    binary_masks = binary_masks.unsqueeze(1).repeat(1, self.n_channels, 1, 1)
    return binary_masks.float()
```

这是整个实现最精妙的地方：一行 `coalition_t[:, region_map]` 替代了循环/坐标列表/scatter 等复杂操作。PyTorch 的 advanced indexing 自动完成 `(N, n_regions)[:, (H, W)] → (N, H, W)` 广播。

### 5. Text mask（复用 PatchSegmenter 逻辑）

```python
# CLIP:    [BOS] [tokens...] [EOS] → BOS+EOS 固定为 1，中间按 coalition 填
# SigLIP:  [tokens...] [padding...] → padding 固定为 1，tokens 按 coalition 填
# SigLIP2: [tokens...] [padding...] → padding 固定为 1，tokens 按 coalition 填（少 1 个）
```

## 发现的 Bug 及修复

### Bug: `n_players_image` 不一致

**现象**：game 报告 `n_players_image=49`（config 值），但 SLIC 实际只产出了 44 个区域。

**根因**：[imputer.py](ImputerFactory/core/imputer.py) 里 `n_players_image` 直接从 config 赋值：
```python
self.n_players_image = config.n_players_image  # 固定值
```
而 `n_players_text` 是从 layout 读取的 property：
```python
@property
def n_players_text(self) -> int:
    return self.layout.n_players_text
```

**修复**：把 `n_players_image` 改为 property，也从 layout 读：
```python
@property
def n_players_image(self) -> int:
    return self.layout.n_players_image
```
