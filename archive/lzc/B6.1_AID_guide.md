# B6.1 — AID (Area Between Insertion/Deletion Curves) 详解

> 2026-05-29

---

## 1. AID 是什么

AID = **Insertion Curve** 和 **Deletion Curve** 之间的面积。衡量解释（attribution）质量的指标，越大越好。

### 实验逻辑

1. 用 FIxLIP 算出一阶归因值 → 每个 player 得到一个"重要性分数"
2. 按分数排序
3. 逐步遮掉 player（MIF: 最重要优先 / LIF: 最不重要优先）
4. 记录每一步的 CLIP 图文相似度
5. 归一化到 [0,1]，算两条曲线之间的面积

### 两条曲线

| 曲线 | 含义 | 好解释的表现 |
|------|------|------------|
| **MIF** (Most Important First) | 优先删最重要的 player | 快速下跌，曲线贴近底部 |
| **LIF** (Least Important First) | 优先删最不重要的 player | 长期保持高位，最后才跌 |

### 归一化

两条曲线都经过 min-max 归一化：
- `v_max` = 完整输入（full coalition）的 CLIP 相似度 → 归一化为 1.0
- `v_min` = 空输入（empty coalition）的 CLIP 相似度 → 归一化为 0.0

两条曲线共享相同的起始点 (1.0) 和终点 (0.0)，区别在**形状**。

```
  1.00 │●╲
       │   ╲╱ ← MIF（快速下跌，弯的）
分数   │  ╱  ╲
       │╱     ● ← LIF（慢速下跌，凸的）
  0.00 │─────────●
      遮0%      遮100%
       └── AID ──┘（绿色面积）
```

- **AID > 0**：归因准确（MIF 比 LIF 跌得快）
- **AID ≈ 0**：随机排序
- **AID < 0**：排序反了（理论不应该出现）

## 6. Mode/Order 组合

| 参数 | 取值 | 含义 |
|------|------|------|
| mode | `shapley` | 经典 Shapley 采样 |
| mode | `banzhaf/0.3` | Banzhaf 采样，p=0.3 |
| mode | `banzhaf/0.5` | Banzhaf 采样，p=0.5（默认） |
| mode | `banzhaf/0.7` | Banzhaf 采样，p=0.7 |
| order | `1` | 一阶交互（单 player） |
| order | `2` | 二阶交互（player 对） |

共 4×2=8 种组合，每种产出独立的 AID 曲线。
